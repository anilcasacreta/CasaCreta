# Eto.Forms Official Reference Links & Developer Resources

## 1. Official McNeel Developer Guides

- **Rhino Developer Guide — Eto Controls**:  
  https://developer.rhino3d.com/guides/rhinocommon/eto-controls/  
  *Covers basic to advanced UI design in Eto using C# and Python.*

- **Rhino Developer Guide — Eto Layouts**:  
  https://developer.rhino3d.com/guides/rhinocommon/eto-layouts/  
  *Detailed comparison of DynamicLayout, TableLayout, PixelLayout, and Scrollable containers.*

- **Rhino Developer Guide — Creating Eto Dialogs**:  
  https://developer.rhino3d.com/guides/rhinocommon/eto-dialogs/  
  *Modal dialog patterns, parent window bindings (`RhinoEtoApp.MainWindow`), and dialog results.*

- **Rhino Developer Guide — Rhino Dockable Panels**:  
  https://developer.rhino3d.com/guides/rhinocommon/eto-panels/  
  *Embedding custom Eto UI panels into Rhino's native tabbed sidebar.*

## 3. Eto.Forms Core Project Resources

- **Eto.Forms Official GitHub Repository**:  
  https://github.com/picoe/Eto  
  *The core cross-platform UI framework created by Curtis Wensley.*

- **Eto.Forms API Documentation**:  
  http://pages.picoe.ca/docs/eto/html/R_Project_Eto.htm  
  *Complete API documentation of classes, properties, and events across `Eto.Forms` and `Eto.Drawing`.*

- **Eto.Forms Wiki & Tutorials**:  
  https://github.com/picoe/Eto/wiki
